About

Pyboot is a collection of python libraries & packages that are used to bootstrap python applications of different types like API backends, database elements, background job runners etc.

Pyboot allows developers to write modular python application, that are easily extensible by implementors, and easily packagable into a larger app. Pyboot goes with a fully object-oriented IOC approach to application development.
